Summary of README.md Content

● Project Title & Badges: Enochian Magic Android Grimoire, built with Kotlin, Jetpack Compose, and Room Database.

● Key Features Overview:

○ Enochian Sanctum Vault: Reference grimoire for 48 Angelic Keys, 91 Aethyrs, Watchtower Tablets, and Sigil Glossary.

○ Sigil Generator & Tracing Engine: Geometric Enochian Rose Wheel tracing, custom palettes, and high-res 1200x1200px PNG exports for physical ritual prints.

○ Sacred Ritual Journal: Working logs with moon phase auto-tagging and filtering.

○ Invocation Progress Tracker: Counter, duration tracking, and audio tone synthesizer (432 Hz, 528 Hz, 396 Hz, 174 Hz).

○ Lunar Calendar & Planetary Hours: Real-time moon illumination and astrological timing calculations.

○ GitHub Sync & Local Backup: Private GitHub repository synchronization with offline ConnectivityManager pre-checks and JSON import/export.

● Architecture & Build Instructions: Detailed breakdown of MVVM setup, tech stack, prerequisites, permissions, and Gradle commands.
